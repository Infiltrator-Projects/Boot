# Historical package definitions

These Debian and RPM definitions are retained as source provenance, including
their licensing and attribution material. They are not current Boot package or
publication definitions.

Boot is the InfiltratorOS component name. A qualified product package must use
Boot's current identity, and the planned graphical Setup installer will own
firmware installation as an explicit transaction.

See [Building Boot](../../../BUILDING.md) and
[Validation and Qualification](../../VALIDATION.md) for the current supported
build evidence and release requirements.
