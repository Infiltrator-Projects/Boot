BOOT — UEFI boot manager
=======================

BOOT is the UEFI boot manager maintained by Infiltrator-Projects.

Repository: https://github.com/Infiltrator-Projects/Boot

This source tree is being rebranded one file at a time. The source,
executable, configuration, installation utilities, packaging, and
documentation must eventually use BOOT consistently.

Do not install a build of this repository until its source-level rename
is complete and its UEFI boot behaviour has been verified.

BOOT must be installed independently of GRUB, without overwriting GRUB,
the firmware fallback at EFI/BOOT, or manufacturer files.

Build instructions are in BUILDING.txt. Licence terms are recorded in
COPYING.txt and the component-specific licence notices; retain applicable
notices and copyright attribution when distributing derivatives.
